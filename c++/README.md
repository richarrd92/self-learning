# C++

Old college projects in C++ and Bash. Each C++ project builds with its own `makefile`.

- `pokemon-game/`: menu-driven Pokémon catching and battling game
- `airline-manager/`: airline route planner using linked lists
- `travel-utopia/`: space exploration game with mining, upgrades and battles
- `movie-player/`: movie catalog and playlist using a templated queue
- `messager/`: Bash script for sending, searching and removing local text messages
