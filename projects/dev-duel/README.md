# Dev Duel

A full-stack GitHub comparison app built to practice Angular, Express, and API data handling together.

## What it does
- fetch GitHub profile data from an API
- compare two user profiles
- show a visual winner based on selected metrics

## Tech used
- Angular front end
- Node/Express API
- GitHub API integration

## Run it
```bash
npm install
npm run serve
```

This starts the API and the Angular client together.
